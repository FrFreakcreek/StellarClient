# Stellar Client (Fabric, Minecraft 1.21.11)

HUD (FPS, CPS, coords, ping, WASD keystrokes), hold-to-zoom, FPS boost preset,
loot beams and a username toggle.

Keys (rebind in Options > Controls > Stellar Client):
H = HUD, C = zoom (hold), B = FPS boost, L = loot beams, N = usernames.
Config: config/stellarclient.json (restart the game after editing).

## Build the jar on GitHub
1. Upload this project to a repo (keep the `src` folder and `.github/workflows/build.yml`).
2. Actions tab > wait for the green check > download the `stellarclient-jar` artifact.
3. Unzip it and put `stellarclient-1.0.0.jar` in your mods folder with Fabric API for 1.21.11.
